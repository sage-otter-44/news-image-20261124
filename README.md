## How the program works

- `render.py` (build-time only) draws the whole image as SVG from the 50 verified stories — masthead, timeline, four illustrated leads, twelve illustrated medium stories, the numbered world map, the 17–50 list and the date-check footer — then rasterises it to `entry.png` (1024×1024) with headless Chromium. All artwork is original vector drawing; no photographs are used.
- `main.ts` (Node 22, standard library only) is the entrypoint: it checks that `entry.png` is a real PNG no larger than 1 MiB and 1024×1024, with a whole IEND chunk, then copies it to `$MAKEFUN_OUTPUT_DIR/entry.png`. It reads nothing else and makes no network calls, so every run writes byte-identical output.
- Verified: `MAKEFUN_OUTPUT_DIR=out1 node main.ts` and `MAKEFUN_OUTPUT_DIR=out2 node main.ts` produce identical SHA-256 hashes; the PNG is 288,037 bytes (limit 1 MiB) at exactly 1024×1024.
